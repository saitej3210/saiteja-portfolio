# Kodi Saiteja — Portfolio (Upgrade V3)

Static HTML/CSS/JS. No build step.

## What's new
- All 10 projects added with live links, categories and filters (All / Web / AI / Business / Creative)
- Project data lives in `projects.js` — edit names, text, tags, links there
- New gradient accent style, glass project cards with 3D hover tilt (`upgrade.css`)
- Updated hero, skills (Python, Flask, React, JS, Three.js, C/Java, ESP32), marquee, stats, SEO meta
- 240-frame scroll character animation kept as is

## V3.1
- Muted terracotta + brass palette (no neon)
- Three.js floating 3D objects (`bg3d.js`) that drift with scroll and mouse
- Cards: 3D scroll entrance, tilt, glare, parallax covers

## Run
Open the folder in VS Code -> right-click `index.html` -> Open with Live Server. Press Ctrl+F5 if cached.
